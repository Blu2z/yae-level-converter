

# YAE Level Converter

Конвертер уровней и моделей из игры «You Are Empty» (форматы DS2/DS2MD) в OBJ.

## Сборка (Linux)

Требуется CMake 3.15+ и компилятор с поддержкой C++17.

```bash
git clone --recurse-submodules <url>
cd yae-level-converter
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

Патчи для совместимости xray_re-tools с Linux применяются автоматически при конфигурации CMake (см. `patches/`).

## Подготовка данных

1. Настроить пути в `fs_yae_converter.ltx`
2. Распаковать текстуры в `gameres/textures/`
3. Распаковать нужные карты в `gameres/maps/`
4. Распаковать модели в `gameres/models/` (для экспорта инстансов моделей)

Распаковывать можно в любые папки — в этом случае правьте пути в `fs_yae_converter.ltx`.

## Использование

**Конвертирование уровней:**
```
yae_converter -level <level_folder> [-out <output_path>] [-mode <max|maya>] [-split] [-scale <factor>]
```

**Конвертирование моделей:**
```
yae_converter -model <model_file> -obj|-object <output_path> [-mode <max|maya>]
```

### Параметры

| Параметр | Описание |
|---|---|
| `-level <name>` | Название папки с картой (med1, map00, map06 и т.д.) |
| `-model <file>` | Путь до файла модели (с расширением) |
| `-out <path>` | Путь до выходного OBJ (без расширения) |
| `-mode <max\|maya>` | Для какого редактора делать OBJ (по умолчанию max) |
| `-split` | Разбить геометрию на несколько файлов по игровому материалу |
| `-scale <factor>` | Масштаб вершин (например `-scale 0.01` для перевода из см в метры) |
| `-obj\|-object` | Выходной формат геометрии модели |

## Что конвертируется

- Геометрия уровня (статические и динамические меши) с корректными трансформами
- Текстурные координаты и нормали
- Материалы (MTL с путями к текстурам)
- Инстансы моделей (если DS2MD-файлы доступны в `gameres/models/`)
